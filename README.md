# Car Price Prediction

## Overview

This project explores car price prediction using machine learning techniques and the Ford car dataset. It uses Python and a Jupyter Notebook to analyze vehicle data and develop a predictive model.

## Dataset

- `ford.csv` – Dataset containing Ford car information for analysis and price prediction.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow

1. Load and explore the dataset.
2. Perform data cleaning and preprocessing.
3. Analyze relevant features.
4. Train a regression model to predict car prices.
5. Evaluate model performance.

## Project Structure

- `ford.csv` – Dataset
- `notebook93e21c35b5.ipynb` – Jupyter Notebook containing the project code.

## Purpose

The purpose of this project is to practice data analysis and machine learning by building a car price prediction model.
